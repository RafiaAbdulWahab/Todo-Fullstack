# Todo Full-Stack Web Application (Phase II) - Overview Specification

## 1. Project Title
Todo Full-Stack Web Application (Phase II)

## 2. Goal
Transform the Phase 1 console app into a modern multi-user web application with persistent storage.

## 3. Development Approach
**Agentic Dev Stack (SDD):** No manual coding.
**Workflow:** Spec -> Plan -> Tasks -> Implement.

## 4. Tech Stack
*   **Frontend:** Next.js 16+ (App Router), TypeScript, Tailwind CSS.
*   **Backend:** Python FastAPI.
*   **ORM:** SQLModel.
*   **Database:** Neon Serverless PostgreSQL.
*   **Authentication:** Better Auth with JWT Tokens.

## 5. Core Features
*   User Signup/Signin.
*   Task CRUD (Create, Read, Update, Delete, Toggle Complete).
*   User Isolation (Users only see their own tasks).
*   RESTful API Endpoints.
